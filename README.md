У ході виконання лабораторної роботи я практично засвоїв основні принципи інкапсуляції в C#. Реалізував клас BookCollection, у якому приховав внутрішні дані (список елементів) та надав до них безпечний доступ через публічні властивості з валідацією. Також я реалізував індексатор для зручного доступу до елементів за індексом, перевантажив оператори +, == та != для інтуїтивної роботи з об'єктами колекції та навчився коректно перевизначати класичні методи Equals() і GetHashCode(). Роботу успішно протестовано та завантажено на GitHub.
